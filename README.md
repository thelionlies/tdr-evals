# TDR Evals

Evaluation code, benchmark, and results for the [TDR: Tagalog Diacritic Restoration Dataset](https://huggingface.co/datasets/tdr-research-team/tdr-dataset).

## Structure

```
tdr-evals/
├── data/             ← benchmark and input data
├── models/           ← links to finetuned models on Hugging Face
├── outputs/          ← raw model outputs (answer files per model/condition)
├── evals/            ← evaluation notebooks (per model and format)
└── analysis/         ← summary notebook with results tables and visualizations
```

## Links

- **Dataset:** [tdr-research-team/tdr-dataset](https://huggingface.co/datasets/tdr-research-team/tdr-dataset) (Hugging Face)
- **Models:** [tdr-research-team/models](https://huggingface.co/tdr-research-team/models) (Hugging Face)
